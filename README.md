# AI Oak Orchestrator

This repository contains both the backend and frontend components of the AI Oak Orchestrator system.

## Project Structure

- `backend/`: Go-based orchestrator server.
- `frontend/`: Vue-based web management interface.

## Quick Start

You can run the entire system using Docker Compose from the root directory:

```bash
docker compose up
```

For specific instructions on each component, please refer to the `README.md` in their respective directories.
